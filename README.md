# القمة للمقاولات والديكور | Al-Qimma Contracting & Decor

الموقع الرسمي الاحترافي لشركة **القمة للمقاولات والديكور**، المتخصصة في التصميم الداخلي والمعماري ثلاثي الأبعاد، أعمال التشطيبات الفاخرة وتسليم المفتاح، والمقاولات العامة.

---

## 🚀 كيفية الرفع والتشغيل على استضافة GitHub Pages بسهولة

تم تجهيز الموقع ليعمل على **GitHub Pages** بكل سلاسة وبأكثر من خيار لتناسب رغبتك:

### 🌟 الخيار الأول: النسخة المستقلة الصافية (Pure HTML, CSS, JavaScript)
**الأسهل والأسرع، تعمل بدون أي برامج تثبيت أو أوامر (No Node/NPM needed):**
1. ادخل إلى المجلد: `pure-html-css-js/`
2. ستجد بداخله:
   - `index.html` (ملف HTML5 الأساسي للموقع بالكامل)
   - `style.css` (ملف التنسيقات وتأثيرات التصميم)
   - `script.js` (ملف الجافاسكريبت التفاعلي للحاسبة، السلايدر، والنوافذ)
   - مجلد `images/` (صور المشاريع عالية الدقة)
3. ارفع هذه الملفات مباشرة إلى مستودعك على GitHub في الفرع الرئيسي (`main`).
4. من إعدادات المستودع في GitHub:
   - اذهب إلى **Settings** ➡️ **Pages**
   - عند **Source** اختر `Deploy from a branch`
   - حدد الفرع `main` والمجلد `/ (root)` ثم اضغط **Save**.
   - مبروك! سيعمل موقعك مباشرة على رابط `https://<username>.github.io/<repo-name>/`.

---

### ⚙️ الخيار الثاني: النشر التلقائي عبر GitHub Actions (Vite / React)
إذا أردت رفع المستودع كاملاً وتركه يُبنى تلقائياً:
1. قمنا بإنشاء ملف النشر التلقائي لك في المسار: `.github/workflows/deploy.yml`.
2. ارفع المشروع إلى GitHub.
3. من إعدادات المستودع: **Settings** ➡️ **Pages** ➡️ اختر في **Source**: `GitHub Actions`.
4. سيقوم GitHub ببناء الموقع ونشره تلقائياً عند كل تحديث في غضون ثوانٍ.

---

### 📁 الخيار الثالث: مجلد `dist` المترجم (Compiled Production)
- عند تشغيل أمر `npm run build`، يُنشئ النظام مجلد `dist/` الذي يحتوي على ملفات HTML وCSS وJS مدمجة ومضغوطة بأعلى سرعة تحميل مع مسارات نسبية `./` متوافقة 100% مع استضافات GitHub Pages وNetlify وVercel.

---

## 🛠️ الخدمات والمزايا المضمنة في الموقع:
- **معرض أعمال وتصاميم حية:** فلل، قصور، صالونات، ومكاتب تجارية مع نوافذ عرض وتفاصيل الخامات.
- **مقارنة تفاعلية قبل وبعد (Before & After):** شريط سحب لمشاهدة مرحلة التأسيس والهيكل مقابل التشطيب النهائي.
- **حاسبة التكلفة والمدة التقديرية الذكية:** حساب التكلفة للمتر المربع والإجمالي والمدة التقديرية بالريال السعودي.
- **إرسال ومحادثة واتساب مباشرة:** تصدير تفاصيل المشروع ومقايسة الأسعار مباشرة إلى الواتساب بضغطة واحدة.
- **نموذج حجز استشارة هندسية:** توليد رقم مرجعي للطلب وإشعار تأكيد فوري.
